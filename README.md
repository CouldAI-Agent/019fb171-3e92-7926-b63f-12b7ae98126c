# Presentation App

A Flutter application that presents the "Enhancing Digital Experience with Mobile Apps" presentation.

## Overview
This application displays a series of interactive presentation slides about how mobile applications improve digital experiences for users and businesses. It features an easy-to-use navigation system to move between slides.

## Features
- Interactive slide viewer
- Next/Previous slide navigation
- Progress indicator
- Responsive layout that adapts to different screen sizes

## Setup Instructions
1. Ensure Flutter is installed on your machine.
2. Clone this repository.
3. Run `flutter pub get` to fetch dependencies.
4. Run `flutter run` to start the application.

## Tech Stack
- Flutter
- Dart
- Material Design 3
